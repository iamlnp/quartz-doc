# 基本概念
WORM（write once，read many），即一写多读。当前存储领域对数据安全的要求越来越高，某些特定的文件要求在写入后只能读取，不能进行修改或删除。WORM可以实现这一功能，有效保证企业数据的安全。



# 竞品调研


## H3C ONEStor 3.0分布式存储系统
## worm时钟
为避免存储集群本地时间的改变导致文件的实际保护时间发生变化，ONEStor设计了一套独立的时钟，即WORM时钟来独立计算文件的过期时间。
WORM时钟与集群时间的关系：

- 若WORM时钟小于集群时间，WORM时钟将每隔30秒，向前追赶1秒进行调整，直到赶上集群时间。
- 若WORM时钟大于集群时间，WORM时钟将直接调整为集群时间。
### 概念
**worm属性**
WORM属性包含最大保护期、最小保护期、默认保护期和自动提交时间四个参数。

当为指定目录创建WORM属性后，该目录即成为WORM根目录，其下所有新建子目录和新建文件将自动继承该WORM根目录的WORM属性。
- 最小保护期：系统对文件保护时长的下限，取值需小于等于最大保护期。
- 最大保护期：系统对文件保护时长的上限，取值需大于等于最小保护期。
- 默认保护期：当用户未设置文件的过期时间时，系统对文件的默认保护时长，取值范围在最小保护期和最大保护期之间，也可等于最小保护期或最大保护期。
- 自动提交时间：文件修改完成后，当超过自动提交时间未被再次修改，则自动进入保护状态。文件进入保护状态状态后，只允许读取，不允许修改或删除。

**worm文件状态**
WORM文件的状态改变由WORM状态机控制。WORM状态机会根据当前WORM文件的状态、WORM属性与WORM时间来计算WORM文件继续保持当前状态或是进入哪种状态。不同的状态对应不同的权限，进而实现对WORM文件的保护

|状态|说明|
|--|--|
|未保护|未提供保护服务，此状态下文件可以被修改或删除|
|保护|提供保护服务，该状态下文件只可以读取，不可以修改或删除|
|过期|文件可以读取和删除，是否可以修改则由过期文件策略决定|

### 原理
![图 1](b51c774c8373a6bee514af8dc764b0c5bf3f0939b957955a43ce38cc3fe4d722.png)  

- Operation 1提交保护：通过自动提交保护和手动提交保护两种方式使WORM目录下的文件进入“保护状态”。
  -  自动提交保护：在设置的自动提交保护时间内没有进行写操作和修改WORM属性等操作，文件将自动进入“保护状态”。
  -  手动提交保护：用户手工去除文件写权限或设置为只读，使文件进入“保护状态”。
- Operation 2过保护期：随着时间推移，文件进入“过期状态”，此时文件可以读取和删除，是否可以修改则由过期文件策略决定。
- Operation 3延长保护期：文件过期后，可以通过手动延长保护期使文件重新进入“保护状态”。
- Operation 4修改保护期：文件处于保护状态时，可以通过修改atime，手动延长文件的保护期。

### 过期时间计算
每个文件都具有atime、ctime和mtime三个时间属性，用户可通过stat filename命令查看。
- atime：最后一次读取或执行文件的时间。
- ctime：文件的属性最后改变的时间。
- mtime：文件的数据内容最后改变的时间。

当文件进入保护状态后，atime将不再随文件的读取或执行发生变化，转为表示文件的过期时间，最大值为2106-02-07 14:28:15。
过期时间的计算分为以下两种情况：
- 自动提交保护： atime=mtime+自动提交时间+默认保护期
- 手动提交保护：atime=当前WORM时钟时间+默认保护期

## 华为OceanStor
### 相关概念
**WORM法规时钟**
存储系统为防止由于系统时间被篡改而导致文件的保护期被修改提供了WORM法规时钟。WORM法规时钟包括全局安全法规时钟和WORM文件系统法规时钟。

|时钟分类|作用范围|详细说明|
|--|--|--|
|全局安全法规时钟|整个存储系统内部维护一个全局安全法规时钟，该时钟为所有WORM类型的文件系统提供时钟源。|在首次创建WORM文件系统时，系统管理员必须初始化全局安全法规时钟，初始化成功后不能再修改。|
|WORM文件系统法规时钟|每个WORM文件系统内部维护一个法规时钟，文件的保护期以此时钟为基准。|在创建WORM文件系统时，系统会自动使用全局安全法规时钟初始化WORM文件系统法规时钟，无需用户手动初始化。|

WORM文件系统法规时钟每小时会用全局安全法规时钟进行一次校正，校正规则如下：

- 如果当前WORM文件系统法规时钟大于全局安全法规时钟，将WORM文件系统法规时钟设置成全局安全法规时钟的值。
- 如果当前WORM文件系统法规时钟小于全局安全法规时钟，当两者相差不大于138秒时，将WORM文件系统法规时钟设置成全局安全法规时钟的值；当两者相差大于138秒时，将WORM文件系统法规时钟的值增加138秒。

**文件状态**
|状态|详细说明|
|--|--|
|初始状态|所有新建文件均处于该状态，此时文件是可读、可写状态，所有用户可以对文件进行任意改动。|
|锁定状态|处于该状态的文件，所有用户都不能修改、删除或重命名，只能读取和查看属性。|
|过期状态|处于该状态的文件，所有用户可以删除、读取及查看状态，但是不可以修改和重命名|
|追加状态|处于该状态的文件，所有用户只能以追加的方式向文件末尾添加内容，不能删除、截断或重命名。|

**文件签名**
文件签名主要用于校验文件的完整性。WORM文件系统中文件签名是指文件在进入锁定状态时存储系统自动计算的文件指纹。例如，当存储WORM文件系统的硬盘出现故障，修复后为了确保WORM文件系统中的文件没有被破坏，此时可以通过校验文件签名确认文件是否完整。

**文件系统worm属性**
当为文件系统配置了WORM特性后，文件系统具有WORM属性，这些属性参数作用于放入WORM文件系统中的文件。系统通过文件的WORM属性，判断该文件何时进入锁定状态，何时过期。

|属性|说明|
|--|--|
|模式|当前系统仅支持法规遵从模式|
|最小保护期|WORM文件系统支持的最短保护时间。为WORM文件系统中的各文件设置保护期时，文件的保护期最小不能小于WORM文件系统的最小保护期。|
|最大保护期|WORM文件系统支持的最长保护时间。为WORM文件系统中的各文件设置保护期时，文件的保护期最大不能大于WORM文件系统的最大保护期。|
|默认保护期|WORM文件系统支持的默认保护时间。当放入WORM文件系统中的文件未设置保护期时，文件的保护期为WORM文件系统的默认保护期。|
|自动锁定|开启自动锁定功能后，放入WORM文件系统中的文件在结束修改超过特定一段时间（锁定等待时长）后自动进入锁定状态，修改包括修改文件数据和元数据两种类型的操作。|
|锁定等待时长|修改完成的文件自动进入保护状态的默认等待时间，“自动锁定”被启用的情况下该属性才有效。|
|自动删除|开启自动删除功能后，存储系统会自动删除已经过了保护期的文件，即自动删除过期文件。|

**文件进入保护状态**
于锁定状态的文件受到保护，此时文件只能读取，不能修改、删除或者重命名。可以采用两种方式使WORM文件系统中的文件进入锁定状态。
- 自动提交保护：WORM文件系统中的文件在结束修改超过“锁定等待时长”后，将自动进入锁定状态。
- 手动提交保护：WORM文件系统中的文件，用户手动去除文件写权限或设置为只读，将立即触发文件进入锁定状态。

**过期时间**

每个文件都具有“访问时间”（atime）属性，该属性表示文件最后一次被访问的时间。对于具有WORM属性的文件来说，atime表示该文件的过期时间，超过该时间，文件将不再受到保护。当文件进入锁定状态后，atime不会随文件被访问而改变。atime的计算分为以下两种情况：

- 自动提交保护场景：无论用户是否设置atime，atime为文件最后完成修改时的WORM文件系统法规时钟加上锁定等待时长再加上默认保护期
- 手工提交保护场景
  - 如果用户未设置atime，则atime为当前WORM文件系统法规时钟加上默认保护期。
  - 如果用户设置atime，但atime小于等于当前系统时钟，则atime为当前WORM文件系统法规时钟加上默认保护期。
  - 如果用户设置atime，但atime小于当前WORM文件系统法规时钟加上最小保护期，同时大于当前系统时钟，则atime为当前WORM文件系统法规时钟加上最小保护期。
  - 如果用户设置atime，但atime大于当前WORM文件系统法规时钟加上最大保护期，则atime为当前WORM文件系统法规时钟加上最大保护期。
  - 如果用户设置atime，且atime大于等于当前WORM文件系统法规时钟加上最小保护期，同时小于等于当前WORM文件系统法规时钟加上最大保护期，则atime为用户设置的值。

### 原理

WORM技术使文件只能写入一次数据，不能重复写入且不允许被修改、删除或重命名。WORM特性是在普通文件系统的基础上增加了WORM属性，使WORM文件系统内的文件在保护期内只能被读取。创建WORM文件系统后，通过NFS或者CIFS协议映射给应用服务器。

通过使用WORM特性，存在于WORM文件系统中的文件可以在初始状态、锁定状态、追加状态以及过期状态之间进行转换，从而防止重要数据在指定周期内被意外或恶意纂改。

![image-20220224162150988](/Users/liunaipeng/Documents/trainning/存储特性调研/WORM/image-20220224162150988.png)

1. 初始状态 –> 锁定状态：文件可以通过两种方式从初始状态转换至锁定状态。
   - 在自动锁定模式打开的情况下，文件结束修改后超过“锁定等待时长”自动进入锁定状态。
   - 手动将文件设置成锁定状态，在设置锁定状态前可以明确给出文件的保护期，也可以使用系统默认的保护期。
2. 锁定状态 –> 锁定状态：当文件处于锁定状态时，可以手动延长文件的保护期。保护时间只能延长不能缩短。
3. 锁定状态 –> 过期状态：在WORM文件系统的法规时钟超过文件过期时间之后，文件就会由锁定状态转换至过期状态。
4. 过期状态 –> 锁定状态：通过延长文件的保护期，可以实现文件从过期状态转换至锁定状态。
5. 锁定状态 –> 追加状态：通过去掉文件的只读权限，将处于锁定状态的文件设置成追加状态。
6. 追加状态 –> 锁定状态：通过设置文件为只读状态，将处于追加状态的文件设置为锁定状态，以保证文件不再被修改。
7. 过期状态 –> 追加状态：可手动将处于过期状态的文件设置成追加状态。

## 浪潮AS13000

系统管理员将WORM根目录配置完成后，用户通过Windows客户端访问文件系统，根据业务需求将需要保护的文件放入文件系统中，通过设置宽限期和超时时间形成保护期，在保护期内，客户端不能对设置WORM功能的共享目录进行修改、删除和移动，只能读取。

**worm宽限期**

从文件最后一次被写入算起，若超过用户设置的宽限期，则该共享目录进入WORM保护状态，即被设置为只读状态。

**worm超时时间**

共享目录进入WORM保护状态后，所有用户能够读取该目录中已存在文件以及写入新文件，但无权对其进行任何修改或删除操作，等到达用户设置的超时时间后，WORM保护状态失效，共享目录只读状态失效，此时允许用户对该共享目录的内容进行修改、删除、读取等各种操作。AS13000对CIFS共享客户端提供WORM功能，通过设置宽限期和超时时间形成保护期。在保护期内，CIFS共享客户端不能对设置WORM功能的共享目录下的文件进行修改、删除和移动操作，只能读取。关闭WORM功能之后，CIFS共享客户端能对共享目录进行正常的读写操作。

**worm文件状态**

![image-20220228140423715](/Users/liunaipeng/Documents/trainning/存储特性调研/WORM/image-20220228140423715.png)

- 当共享目录处于“**未保护状态**”时，与普通文件一样，能够进行读取、修改、删除和移动操作。
- 开启WORM功能。查看WORM功能是否已经开启，若开启且不需要修改保护期时长，则直接返回已开启；若未开启，则开启WORM并设置WORM功能的宽限期和超时时间，重启CIFS共享服务，使WORM配置生效。
- WORM功能开启之后，共享目录进入“保护状态”，该状态下用户只能读取，不能进行修改、删除和移动。
- 当共享目录过期之后，能够对该共享目录下的内容进行正常的读写和删除操作。

###  过期时间计算

| 产品      | 计算方式                                                     |
| --------- | ------------------------------------------------------------ |
| OneStor   | 当文件进入保护状态后，atime将不再随文件的读取或执行发生变化，转为表示文件的过期时间。过期时间的计算分为以下两种情况：<br />（1）自动提交保护： atime=mtime+自动提交时间+默认保护期 <br />（2）手动提交保护：atime=当前WORM时钟时间+默认保护期 |
| OceanStor | 对于具有WORM属性的文件来说，atime表示该文件的过期时间，超过该时间，文件将不再受到保护。当文件进入锁定状态后，atime不会随文件被访问而改变。<br />（1）自动提交保护场景：无论用户是否设置atime，atime为文件最后完成修改时的WORM文件系统法规时钟+锁定等待时长+默认保护期<br />（2）手工提交保护场景：<br />        （2.1）如果用户未设置atime，则atime为当前WORM文件系统法规时钟+默认保护期。<br />        （2.2）如果用户设置atime，但atime小于等于当前系统时钟，则atime为当前WORM文件系统法规时钟+默认保护期。<br />        （2.3） 如果用户设置atime，但atime小于当前WORM文件系统法规时钟加上最小保护期，同时大于当前系统时钟，则atime为当前WORM文件系统法规时钟+最小保护期<br />        （2.4）如果用户设置atime，但atime大于当前WORM文件系统法规时钟加上最大保护期，则atime为当前WORM文件系统法规时钟+最大保护期<br />        （2.5）如果用户设置atime，且atime大于等于当前WORM文件系统法规时钟加上最小保护期，同时小于等于当前WORM文件系统法规时钟加上最大保护期，则atime为用户设置的值。 |
| AS13000   | 设置宽限期和超时时间形成保护期，从文件最后一次被写入算起，若超过用户设置的宽限期，则该共享目录进入WORM保护状态<br />等到达用户设置的超时时间后，WORM保护状态失效 |
