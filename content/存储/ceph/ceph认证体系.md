# 基本概念
共享密钥（Shared Key），也叫 “对称密钥”，是**通信双方 / 多方预先约定、共同持有且保密的一串字符 / 数值**，用于：
- 加密：发送方用该密钥加密明文；
- 解密：接收方用同一密钥解密密文；
- 认证：验证通信方身份（如确认对方持有相同密钥）。
**核心特征**
1. **对称性**：加密和解密使用同一密钥，算法简单、加解密速度快（适合大数据量加密）；
2. **保密性**：密钥必须严格保密，一旦泄露，所有加密数据可被破解；
3. **分发风险**：需通过安全渠道（如离线传递、加密通道）分发，否则易被截获；
4. **常见算法**：AES、DES、3DES、RC4 等（AES 是目前主流的共享密钥加密算法）。
