# 算法代码
## 整体代码
```c++
void quicksort(vector<int> &vec, int l, int r) {
	if (r <= l) return;		//避免越界
	int pos = partision(vec, l, r);
	quicksort(vec, l, pos - 1);
	quicksort(vec, pos + 1, r);
}
```
## 划分处理
快速排序最重要的处理就是如何划分两段区域
下面有两种方法：
- 同向双指针
- 反向双指针

### 同向双指针
起始将P1指向-1位置，P2指向1位置，P1的含义是已经发现的最后一个小于选定值Key的位置，P2向后遍历。

将选定元素Key交换到尾部，每次P2发现一个比Key小的元素，将其与P1交换，P1向右移动一个位置，P1左侧一定是比Key小的元素。

P2遍历完毕之后，将P1将指向最后一个小于选定值的位置，将其与最后一个元素交换位置，那么P1位置即分界点。

代码如下：
```c++
int partision(vector<int> &vec, int lo, int hi) {
	int p1 = lo - 1;
	int p2 = lo;
	
	int pos = random(lo, hi);  //随机返回lo和hi之间的一个位置
	swap(vec, hi, pos)  //将pos位置值交换到末尾
	
	//i没必要等于hi，否则多一次无用的循环
	for (int i = p2; i < hi; i++) {
		if (vec[i] < vec[pos]) {
			p1++;
			swap(vec, p1, i);
		}
	}
	
	p1++;	//指向下一个位置
	swap(vec, p1, hi);	//将选定位置交换，p1即分界点
}
```

### 反向双指针
选定一个元素Key，通常是最左侧元素Pos；或者可以随机选择一个位置Pos。

P1指向最左侧位置，P2指向最右侧位置，P1向右移动，直到找到第一个比Key大的元素，P2向左移动，直到找到第一个比Key小的元素，交换P1和P2的值，如果P1 >= P2, 则退出

这样P2位置是比Key小的位置，将Pos和P2的值交换，Pos左侧都是比Key小，右侧都是比Key大，Pos即分界点。

代码如下：
```c++
int patision(vector<int> &vec, int lo, int hi) {
	int p1 = lo;
	int p2 = hi;
	int pos = random(lo, hi);
	
	int key = vec[pos];
	
	while(true) {
		while (vec[p1] < key && p1 < hi) p1++;
		while (vec[p2] > key && p2 > lo) p2++;
		if (p2 >= p1) break;
		swap(vec, p1, p2);
	}
	
	swap(vec, pos, p2);
}
```
