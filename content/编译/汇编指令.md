
# 1 push
PUSH 是汇编语言中的一条指令，用于将数据压入栈（stack）中。栈是一种后进先出（LIFO，Last In First Out）的数据结构，广泛用于函数调用、局部变量存储、参数传递等。
## 1.1 **指令功能**
• 将操作数（寄存器值、立即数或内存地址中的数据）压入栈中。
• 栈指针寄存器（通常是 ESP/RSP，32 位/64 位 x86 架构中的栈指针）会根据数据的大小进行调整。
## 1.2 **栈的基本结构**
栈通常向低地址增长：
• 栈顶由栈指针寄存器（ESP/RSP）指向。
• PUSH 指令执行时，栈指针递减（因为数据压入栈顶后，栈顶地址变小），然后将数据写入新的栈顶位置。
## 1.3 **指令格式**
```shell
PUSH operand
```
operand 可以是：

• **寄存器**：如 `PUSH AX`、`PUSH EAX`、`PUSH RAX`（16 位、32 位、64 位寄存器）。
• **立即数**：如 `PUSH 5`。
• **内存地址**：如 `PUSH [EBX]`（将 EBX 寄存器指向的内存单元中的值压入栈中）。

## 1.4 **工作过程**

以 32 位 x86 架构为例，执行 PUSH 指令的步骤：

1. **栈指针递减**：ESP 减少 4 个字节（32 位系统，栈每次操作 4 字节）。
2. **数据写入栈顶**：将操作数写入由 ESP 指向的内存位置。
在 64 位系统中（x86-64 架构），RSP（栈指针寄存器）会减少 8 字节，并且压入的数据也是 8 字节（64 位）。
## 1.5 举例
```assembly
PUSH EAX     ; 将 EAX 寄存器的值压入栈中
PUSH 10      ; 将立即数 10 压入栈中

PUSH RAX     ; 将 RAX 寄存器的 64 位值压入栈中
PUSH 12345678h ; 将立即数 12345678h 压入栈中
```
## **栈指针变化**
在 32 位 x86 系统上，假设栈指针 ESP 当前值为 0x0010FFFC，EAX 的值为 0x12345678，并执行以下指令：
```asm
PUSH EAX     ; 将 EAX 寄存器的值压入栈
```
执行后，栈的变化如下：
• ESP 从 0x0010FFFC 变为 0x0010FFF8（因为栈是向下增长的，栈指针减小 4 字节）。
• 0x0010FFF8 内存地址处存储值 0x12345678（EAX 中的值）。
## **与 POP 配合使用**
PUSH 和 POP 常成对出现，POP 指令从栈顶弹出数据并存入指定的寄存器或内存位置，栈指针随后递增。通过这两个指令，可以轻松实现函数调用和返回时的局部变量管理、寄存器值保存等。
```asm
PUSH EAX  ; 将 EAX 寄存器的值压入栈
POP  EBX  ; 从栈顶弹出数据，并将其存入 EBX 寄存器
```
执行后，EBX 将持有 EAX 原先的值。
