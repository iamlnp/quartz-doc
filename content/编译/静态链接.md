# 1 空间与地址分配

## 1.1 空间分配

- 按序叠加： 直接间各个目标文件依次合并
- 相似段叠加： 将相同性质的段合并到一起

链接步骤：

1. 空间与地址分配
2. 符号解析与重定位

下面是两个文件：

```c
//a.c
extern int shared;
int main()
{
  int a = 100;
  swap(&a, &shared);
}

//b.c
int shared = 1;
void swap(int *a, int* b)
{
  *a ^= *b ^= *a ^= *b;
}
```

编译`gcc -c a.c b.c`, 得到a.o、b.o，链接`ld a.o b.o -e main -o ab`，观察各个段的属性(**VMA**虚拟机地址，**LMA**加载地址)

# 2 静态库链接

一个静态库可以简单看做**一组目标文件的集合**，即很多目标文件经过压缩打包形成的一个文件。可以使用`ar`命令查看包含哪些目标文件。

```shell
[root@liunp ~]# ar -t /home/thinkfs/build/lib/libtfs_ioa.a
tfs_ioa_beacon.cc.o
tfs_ioa_daemon.cc.o
tfs_ioa_session.cc.o
tfs_ioa_server.cc.o
tfs_ioa_node.cc.o
tfs_ioa_service.cc.o
tfs_scrub.cc.o
tfs_worm.cc.o
tfs_ioamap.cc.o
tfs_ioa_test.cc.o
```

`ar -x`可以将静态库解压到当前目录。
